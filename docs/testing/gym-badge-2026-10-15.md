# Gym badge visibility — 2026-10-15

## Fix

The career shell treated the default Original corner look as missing because the achievements API intentionally represents that selection as `null`. It rendered a text fallback instead of the crest. A separate phone rule hid the top-bar crest below 420px.

The frontend now resolves the original look to the founding glove crest, shares that identity with Home/Gym, and always renders the top-bar and sidebar illustrations. Narrow phones retain a smaller badge. Earned looks continue to use their selected colors and symbol. No persisted selection, ownership or game rules changed.
